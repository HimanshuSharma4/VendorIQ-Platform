# VendorIQ - Reliability Intelligence Platform

Enterprise-grade vendor reliability and procurement management dashboard built for modern businesses.

## 🚀 Live Demo
[View Live Application](https://vendor-iq-platform.vercel.app)

## 🛠️ Tech Stack
* **Frontend:** Angular, TypeScript, Tailwind/CSS
* **Backend:** Python, FastAPI, SQLAlchemy
* **Database:** PostgreSQL (Neon)
* **Hosting:** Vercel (Frontend) & Render (Backend)

## ✨ Features
* Comprehensive Admin & Vendor Dashboards
* Real-time Procurement Analytics & Spend Trends
* Vendor Risk Distribution & Performance Tracking
* Secure Authentication & Role-based Access Control
